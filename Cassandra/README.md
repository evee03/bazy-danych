# Apache Cassandra - System Bazy NoSQL

Projekt wykorzystujący Apache Cassandra czylirozproszoną, skalowalną bazę NoSQL do obsługi dużych zbiorów danych. Celem jest pokazanie możliwości modelowania danych w bazie kolumnowej oraz efektywnego zapytań za pomocą języka CQL.

## Apache Cassandra vs Relacyjne Bazy Danych (SQL):

- **Model kolumnowy** - zoptymalizowany pod kątem zapytań odczytowych
- **Brak JOIN-ów** - denormalizacja danych na rzecz szybkości i skalowalności
- **Wysoka dostępność** - rozproszona architektura bez pojedynczego punktu awarii
- **Elastyczna replikacja** - konfigurowalna strategia replikacji danych
- **CQL** - język zapytań podobny do SQL, ale dostosowany do modelu NoSQL
